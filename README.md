# Front (Vue 3 + Vite)

Цей фронтенд реалізує базовий флоу авторизації на клієнті та навігацію між сторінками.

## Можливості
- Сторінка Входу (логін/пароль), помилки валідації, редірект на попередній запитаний маршрут або на "Головна".
- Сторінка Реєстрації з перевіркою складності паролю та підтвердженням.
- Сторінка "Забули пароль?" (демо-повідомлення про відправлення інструкцій).
- Хедер з навігацією: Головна, Кібернетичний простір, Комунікаційне середовище, Фізичний рівень, Вихід.
- Захищені маршрути (доступні лише після входу), гостьові маршрути (доступні лише до входу).
- Демонстраційний стан авторизації у localStorage (без бекенда).

## Швидкий старт

```sh
# Встановити залежності
cd front
yarn install

# Режим розробки
yarn dev

# Продакшн-збірка
yarn build

# Перегляд прод-збірки
yarn preview
```

Відкрийте посилання з консолі (звичайно http://localhost:5173) для dev/preview.

## Структура
- `src/router/index.js` — маршрути і навігаційні guard'и.
- `src/stores/auth.js` — простий клієнтський стор для авторизації (localStorage).
- `src/pages/*` — сторінки: Login, Register, ForgotPassword, Home, CyberSpace, Communication, Physical.
- `src/components/HeaderNav.vue` — хедер з навігацією та кнопкою "Вихід".

## Примітка щодо безпеки
Поточна авторизація — лише демо на клієнті. Для реального застосунку додайте бекенд-API (login/register/reset), збереження токена, перевірку на сервері та на клієнті.
